# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability, we encourage you to let us know right away.

We will investigate all legitimate reports and do our best to quickly fix the problem.

Please report any vulnerabilities in our open source repositories to security@puckeditor.com.

More details of our vulnerability disclosure program [here](https://trust.puckeditor.com/?tab=vulnerabilityDisclosure).
