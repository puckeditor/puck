# actionBar

Override the action bar. Use the [`<ActionBar>` component](/docs/api-reference/components/action-bar) to extend the default ActionBar UI.

```tsx copy
import { ActionBar } from "@puckeditor/core";

const overrides = {
  actionBar: ({ children, label }) => (
    <ActionBar label={label}>
      <ActionBar.Group>{children}</ActionBar.Group>
    </ActionBar>
  ),
};
```

## Props

| Prop                              | Example          | Type      |
| --------------------------------- | ---------------- | --------- |
| [`children`](#children)           | `<div />`        | ReactNode |
| [`dragHandle`](#draghandle)       | `<div />`        | ReactNode |
| [`dragHandleRef`](#draghandleref) | `(el) => {}`     | Ref       |
| [`label`](#label)                 | `"HeadingBlock"` | String    |
| [`parentAction`](#parentaction)   | `<div />`        | ReactNode |

### `children`

A fragment containing the default [actions](/docs/api-reference/components/action-bar-action). Normally rendered inside an [`<ActionBar.Group>`](/docs/api-reference/components/action-bar-group).

### `dragHandle`

The default drag handle action to drag the current component.

`undefined` unless [`dnd.enableDragHandle`](/docs/api-reference/components/puck#enabledraghandle) is enabled.

### `dragHandleRef`

A `ref` to register your own element as the drag handle.

`undefined` unless [`dnd.enableDragHandle`](/docs/api-reference/components/puck#enabledraghandle) is enabled.

Only use this if not rendering the provided [`dragHandle`](#draghandle) node.

### `label`

The default label for the action bar.

### `parentAction`

A single [`<ActionBar.Action>`](/docs/api-reference/components/action-bar-action) to select the current component's parent.
