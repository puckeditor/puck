# fields

Override the fields wrapper.

```tsx copy
const overrides = {
  fields: ({ children }) => <div>{children}</div>,
};
```

## Props

| Prop                            | Example                            | Type                                                         |
| ------------------------------- | ---------------------------------- | ------------------------------------------------------------ |
| [`children`](#children)         | `<div />`                          | ReactNode                                                    |
| [`fields`](#fields)             | `{ title: <div /> }`               | Object                                                       |
| [`isLoading`](#isloading)       | `false`                            | boolean                                                      |
| [`itemSelector`](#itemselector) | `{ index: 0, zone: "my-content" }` | [ItemSelector](/docs/api-reference/data-model/item-selector) |

### `children`

The default node for the fields.

### `fields`

An object containing the node for each visible field, keyed by field name. Use it to position fields individually.

```tsx copy
const overrides = {
  fields: ({ fields }) => (
    <div>
      {fields.description}
      {fields.title}
    </div>
  ),
};
```

### `isLoading`

Whether the selected item's [fields](/docs/api-reference/configuration/component-config#resolvefieldsdata-params) or [data](/docs/api-reference/configuration/component-config#resolvedatadata-params) are being resolved.

### `itemSelector`

An [`ItemSelector`](/docs/api-reference/data-model/item-selector) for the currently selected item. `null` when no component is selected.
