# \<FieldGroup\>

Render a set of fields in a group.

Use it in [`renderFields`](/docs/api-reference/configuration/component-config#renderfieldsprops) and the [`fields` override](/docs/api-reference/overrides/fields) to create logical groupings.

<PuckPreview
  config={{ components: { Orange: { render: () => <div>Orange</div> } } }}
  data={{ root: { props: {} }, content: [] }}
>
  <FieldGroup label="Appearance">
    <FieldGroupItem>
      <FieldLabel label="Color">
        <AutoField
          value="#000000"
          onChange={() => {}}
          field={{ type: "text" }}
        />
      </FieldLabel>
    </FieldGroupItem>
    <FieldGroupItem>
      <FieldLabel label="Size">
        <AutoField value="12" onChange={() => {}} field={{ type: "number" }} />
      </FieldLabel>
    </FieldGroupItem>
  </FieldGroup>
</PuckPreview>

```tsx {6-13} copy
import { Puck, FieldGroup, FieldGroupItem } from "@puckeditor/core";

export function Editor() {
  return (
    <Puck>
      <FieldGroup label="Appearance">
        <FieldGroupItem>
          <input type="text" value="#000000" onChange={() => {}} />
        </FieldGroupItem>
        <FieldGroupItem>
          <input type="number" value="12" onChange={() => {}} />
        </FieldGroupItem>
      </FieldGroup>
    </Puck>
  );
}
```

## Props

| Param                       | Example               | Type      | Status |
| --------------------------- | --------------------- | --------- | ------ |
| [`children`](#children)     | `children: <div />`   | ReactNode | -      |
| [`expandable`](#expandable) | `expandable: true`    | Boolean   | -      |
| [`icon`](#icon)             | `icon: <svg />`       | ReactNode | -      |
| [`id`](#id)                 | `id: "appearance"`    | String    | -      |
| [`label`](#label)           | `label: "Appearance"` | String    | -      |

## Optional props

### `children`

The fields to render inside the group. Will likely contain [`<FieldGroupItem>`](field-group-item) nodes. Nothing is rendered if there are no children, or only empty strings.

### `expandable`

Hide the children until the label is clicked. **Defaults to `false`**.

### `icon`

Render an icon before the label text. Puck uses [lucide-react](https://lucide.dev/guide/packages/lucide-react) internally.

### `id`

An optional ID for this group, used as the key in [`ui.expandedFieldGroups`](/docs/api-reference/data-model/app-state#uiexpandedfieldgroups). This prop has no effect outside `<Puck>`.

### `label`

The label for the group. Required when [`expandable`](#expandable) is `true`.
