# `RootData`

An object representing the data for the [`root` config](/docs/editor/api-reference/configuration/config#root). Similar to [`ComponentData`](/docs/editor/api-reference/data-model/component-data), but without a `type`, and without an `id` in `props`.

```json
{
  "props": {
    "title": "Hello, world"
  }
}
```

## Params

| Param                   | Example                            | Type   | Status |
| ----------------------- | ---------------------------------- | ------ | ------ |
| [`props`](#props)       | `props: { title: "Hello, world" }` | Object | -      |
| [`readOnly`](#readonly) | `readOnly: { title: true }`        | Object | -      |

### Optional params

#### `props`

The props stored based on the fields of the [`root` config](/docs/editor/api-reference/configuration/config#root), which Puck will pass to the root [`render()`](/docs/editor/api-reference/configuration/component-config#renderprops) method.

```json {2-4} copy
{
  "props": {
    "title": "Hello, world"
  }
}
```

Unlike [`ComponentData`](/docs/editor/api-reference/data-model/component-data), root props don't have an `id`. Defaults to `{}` if not provided.

#### `readOnly`

An object describing which root fields are set to [read-only](/docs/editor/api-reference/configuration/component-config#datareadonly-1).

```json {5-7} copy
{
  "props": {
    "title": "Hello, world"
  },
  "readOnly": {
    "title": true
  }
}
```

## Deprecated root props

<Callout type="warning">
  Storing props directly on `root`, without the `props` key, is deprecated. Use
  [`migrate`](/docs/editor/api-reference/functions/migrate) to move them to
  `root.props`.
</Callout>

```json
{
  "title": "Hello, world"
}
```
